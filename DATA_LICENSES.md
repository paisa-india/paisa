# Data licences and attribution

Paisa's **code** is AGPL-3.0-only. The **data** is not covered by the code licence: each source keeps its own terms. A `.gov.in` address does not by itself mean open reuse, so every source is listed separately. Paisa is independent and does not imply endorsement by any government body.

Datasets published on data.gov.in use the [Government Open Data License – India](https://www.data.gov.in/Godl), which allows reuse with attribution. None of the sources above are taken from data.gov.in yet.

"Review pending" means Paisa uses these official documents to show figures with links and attribution, but their reuse terms for bulk redistribution have not been confirmed. Before raw files from those sources are distributed publicly, check their terms (see [docs/operations.md](docs/operations.md)).

Each source's exact URL, retrieval time and SHA-256 hash are recorded in `data/snapshots/*.json` and shown on the site's Data Sources page.
