# Financial terminology

| Term | Meaning |
|---|---|
| Budget Estimate (BE) | Planned provision for a fiscal year |
| Revised Estimate (RE) | Updated estimate; not actual expenditure |
| Actual | Reported receipts or expenditure for an explicit period; may be provisional |
| Fund release | Amount released to an implementing body; not necessarily spent |
| Sanctioned amount | Approved project provision; not a contract or payment |
| Tender value | Estimated procurement value before award |
| Awarded contract value | Contract commitment; not the amount paid |
| Payment | Recorded disbursement supported by payment evidence |
| Physical progress | Reported implementation progress; not financial utilisation |
| Outcome | A reported result or impact indicator; distinct from expenditure |
| Official | Directly extracted from an official source |
| Derived | Deterministic transformation/aggregation of sourced facts |
| Calculated | Illustrative proportion, such as My Tax |
| Signal | A reproducible mathematical observation, never an accusation |

Financial year: 1 April–31 March. Indian display units: 1 lakh = 100,000; 1 crore = 10,000,000; 1 lakh crore = 1,000,000,000,000 rupees. Hindi glossary text is initial and requires domain-expert review.
